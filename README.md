# KS StreamFlix

> Part of the [KS-Suite](https://github.com/kumasumit/KS-Suite).

A lean, D-pad optimized streaming media manager for Android TV with fast focus navigation and minimal overhead.

| | |
|---|---|
| **Platform** | Android TV |
| **Tech stack** | Kotlin, Jetpack Compose for TV, Media3/ExoPlayer, Room, Hilt |

## Getting started

```bash
git clone --recurse-submodules <repo-url> ks-streamflix
cd ks-streamflix
./gradlew assembleDebug
```

## Release

Releases are cut by pushing a semantic version tag (`git tag v1.2.3 && git push --tags`).
See the suite-level [CI/CD guide](https://github.com/kumasumit/KS-Suite#-cicd-semantic-versioning--automated-signing).
